NCraft 是一款专为全屋定制行业设计的 NC 路径模拟器，是一个纯前端网页应用。它能够直观地展示 NC 加工路径的运行过程，并实时模拟板材的切割、打孔和开槽效果，帮助用户在生产过程中快速排查问题。

核心功能：

NC 路径可视化：以动画方式追踪并预览 NC 代码的执行过程，逐行展示刀具运动轨迹，方便定位加工逻辑问题。
加工效果模拟：支持对常用板材的切割、打孔、开槽效果进行三维仿真展示，所见即所得。
刀具参数配置：可自定义刀具直径，使模拟效果更贴近真实加工场景。
异形与圆弧切割：从 v1.1.23 版本起，采用更高效的 Manifold WASM 布尔运算库替代原有的 Three.js + three-bvh-csg 方案，实现了对异形切割、圆弧切割等复杂加工效果的完美呈现。

技术特点：

零安装、开箱即用：整个应用封装在单个 HTML 文件中，浏览器直接打开即可使用，也可部署到自有 Web 服务器。
双版本分发：提供本地调用版（需搭建服务环境，自带 Manifold WASM 二进制）和远程调用版（推荐，单文件远程加载 JS 库，无需额外配置）。
国内镜像适配：内置多个 Manifold.js 国内镜像源地址，解决国内访问速度问题。
完全免费：作者坦言"做全屋定制的老板都很穷"，因此软件完全免费开放。
适用场景：

主要面向全屋定制/定制家具行业的数控加工环节，可用于 NC 代码编写后的预检验、加工方案评审、生产问题排查等场景，帮助减少实际试切成本，提升生产效率。

# 板材加工NC路径模拟器

从v1.1.23放弃了Three.js + three-bvh-csg的渲染方案，使用了更高效的Manifold WASM 布尔运算库，提高对异形切割，圆弧切割等复杂切割效果的完美展示。
在此提供在线版本，目前搭建在免费的cloudflare page上，如果打不开，你可以下载最新版本压缩包，使用远程调用版（单文件版远程加载JS库），如果不能正常使用可自行修改替换manifold.js镜像源，或者自行在本地搭建服务器使用。

临时在线使用，请访问：
https://ncraft.ixujun.dpdns.org/nc-simulator

包内文件结构：
根目录（Web 站点根 or 子目录）/

├── nc-simulator_local.html          ← 本地调用版，需要搭建服务环境

├── nc-simulator_online.html          ← （推荐）远程调用版，单文件打开即可使用，如果不能正常加载，请替换manifold.js的镜像源地址

└── manifold_local/

    ├── manifold.js            ← Manifold WASM 的 JS 加载器，只有本地搭建服务器时才使用
    └── manifold.wasm          ← Manifold WASM 二进制（布尔运算核心），只有本地搭建服务器时才使用
