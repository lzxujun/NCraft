# 板材加工NC路径模拟器

#### 介绍
这是一个用于模拟全屋定制行业常用NC路径模拟器，除能直观查看NC加工路径的运行过程外，还可以模拟板材的切割和打孔效果，方便在生产过程中查找问题。

#### 软件特点
- 做全屋定制的老板都很穷，所以此软件完全免费
- 能模拟常用板材的加工效果，可以看到切割，打孔，开槽效果
- 可以设置刀具的直径，模拟效果更真实
- 增加了NC代码跟踪预览，方便排查问题



#### 安装教程

1.  不需要安装
2.  单html文件，直接浏览器打开即可
3.  也可部署到自己的web服务器
